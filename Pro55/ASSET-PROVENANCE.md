# Pro-55 artwork and preset credits

The Pro-55 interface was created by **Grant Overend (TrueX Audio)** and includes adapted control artwork from the [Cmajor Pro-54 example](https://cmajor.dev/docs/Examples/Pro54/). Grant reports that Cmajor permitted use of its GitHub content with attribution. Cmajor also confirmed that the Pro-54 project may be shared with other users, provided its GPL source is public so people can download, recompile, and modify it. Cmajor is credited for copied and adapted example artwork; original notices are retained.

The inherited factory sounds come from the Cmajor example. Their source is included at `provenance/presetBank.js`, together with the example's README and upstream licence notice.

The complete source and build instructions are included for public source release. The original Cmajor source notice remains with files marked Cmajor Software Ltd.
